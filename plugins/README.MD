# Fabric-Loom Plugins

Fabric Loom 2.0 uses a modular approach to only apply the features that are required for a given mod.


## User facing plugins

There are 2 user facing plugins that most people will use

### fabric-loom-mod

A plugin to be used on none obfuscated versions of Minecraft, this plugin does not do any remapping

### fabric-loom-mod-remap

A plugin to be used on older versions of Minecraft that requires the game remapped, or for users that wish to continue to apply their own mappings.


### Internal plugins

### fabric-loom-minecraft

A plugin that handles the downloading and running of Minecraft

### fabric-loom-base

A plugin that provides the minimal loom setup as used by other plugins.
